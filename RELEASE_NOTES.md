# ChromePanelFix 9.5 — GUI OPERATIVO

## Español

La versión 9.5 añade una opción de solución manual que aplica los filtros de Google Update, conserva los datos necesarios para DESHACER y no crea ni actualiza ninguna tarea programada. Su submenú permite abrir el Administrador del Servidor al completar la operación o mantenerlo cerrado. La vigilancia independiente pasa a la opción 3; el proceso completo sigue disponible en la opción 4.

La opción manual conserva cualquier tarea ya existente, avisa de ello y no continúa si la tarea propia está ejecutándose. El fallo al abrir el Administrador del Servidor se informa por separado de la reparación.

**Pendiente de verificar:** eficacia de las ejecuciones automáticas de la tarea y compatibilidad con Windows Server 2016. Licencia MIT.

## English

Version 9.5 adds a manual solution path that applies the Google Update filters, preserves the data needed for UNDO, and does not create or update a scheduled task. Its submenu lets the user open Server Manager when the operation completes or leave it closed. Separate monitoring moves to option 3; the complete workflow remains available as option 4.

The manual option preserves any existing task, warns the user, and stops if the tool's task is running. Failure to open Server Manager is reported separately from the repair result.

**Still to verify:** scheduled-task effectiveness and Windows Server 2016 compatibility. MIT License.
