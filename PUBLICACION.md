# Publicación de ChromePanelFix

- Proyecto: **ChromePanelFix**.
- Edición: **9.0 GUI OPERATIVO**, clon funcional de 8.0.
- Repositorio: https://github.com/SenecaDPJ/scriptsgpt
- Descripción: **Gestiona las alertas de Google Update en Administrador del Servidor sin desactivar las actualizaciones de Chrome.**
- Lenguaje: PowerShell, con lector de datos C# integrado.
- Mantenedor: SenecaDPJ.
- Licencia: MIT.
- Temas sugeridos: powershell, windows-server, server-manager, google-chrome, google-update, task-scheduler, windows-forms.

## Distribución

Código y documentación en la raíz del repositorio. ZIP instalable y huella en downloads/.
El ZIP contiene todos los archivos que necesita la aplicación. Extraerlos juntos y abrir Abrir-ChromePanelFix.cmd.
RELEASE_NOTES.md contiene las notas de la edición; su presencia no implica la creación de una GitHub Release o etiqueta.

## Límites publicados

La vigilancia automática y Server 2016 siguen pendientes de validación. Al cerrar MMC, responder «No» al aviso de guardar taskschd.msc.
La 8.0 congelada se conserva localmente.
No se incluyen diagnósticos ni registros privados.
