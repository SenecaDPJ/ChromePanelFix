# Publicación de ChromePanelFix 9.1

- Repositorio: https://github.com/SenecaDPJ/ChromePanelFix
- Versión: 9.1 GUI OPERATIVO, hotfix de distribución sobre 9.0.
- Mantenedor: SenecaDPJ.
- Licencia: MIT.
- Sistema: Windows Server; PowerShell 5.1.

El ZIP contiene la interfaz, el motor, las instrucciones y el lanzador. Extraiga todos los archivos juntos y abra Abrir-ChromePanelFix.cmd. Si Windows bloquea el contenido, desbloquee el ZIP oficial desde Propiedades antes de extraer. No se omite la política de ejecución de la organización.

La eficacia de la tarea automática y la compatibilidad con Windows Server 2016 siguen pendientes. La versión 9.0 se conserva en el historial de Releases.
