# Seguridad

Esta herramienta puede ejecutarse con privilegios de administrador. Revisar el código y usar la cuenta propietaria de las preferencias del panel. No ejecutar copias modificadas de origen desconocido.

No enviar públicamente configuraciones completas, SID, nombres internos, rutas personales ni registros sin revisar. No se incluye telemetría.

Para comunicar una vulnerabilidad tras la publicación, usar «Report a vulnerability» de GitHub si el repositorio lo tiene habilitado. Si no existe ese canal, solicitar al mantenedor un medio privado sin publicar los detalles sensibles. La disponibilidad de ese canal depende de la configuración del repositorio.

No hay plazo de soporte o respuesta garantizado. Las correcciones deberán publicarse en una nueva versión identificable.
