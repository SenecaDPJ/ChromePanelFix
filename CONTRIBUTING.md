# Contribuir

Trabajar sobre la edición publicada 9.0 o su sucesora. Las referencias locales 8.0 y 6.0 del mantenedor están congeladas.

Mantener Windows PowerShell 5.1, reversión selectiva, filtros ajenos, validación de cuenta y ejecución no interactiva de Watch. No eliminar ni deshabilitar componentes de Google.

Para informar de un fallo, incluir versiones de Windows/PowerShell, opción ejecutada, resultado esperado y observado. Revisar y anonimizar registros antes de compartirlos.

Validar sintaxis, reparación/reversión sobre copias y errores de ejecución. Las pruebas simuladas no sustituyen la comprobación en Windows Server ni la ejecución real a las 09:00/al iniciar sesión.

Las contribuciones se ofrecen bajo la licencia MIT incluida.
